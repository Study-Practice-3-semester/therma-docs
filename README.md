# Документация проекта: Интеллектуальная система рекомендаций по управлению воздухонагревателями 

## Навигация по разделам

### 1. Архитектура и Системный дизайн
Раздел с высокоуровневым описанием системы и планом разработки.
* [Feature Breakdown Structure (FDD)](./architecture/fdd_features.md) — Декомпозиция проекта на фичи. Главный план задач для команды.
### 2. Бизнес-логика и моделирование
Описание «интеллектуального» и расчетного ядра системы.
* [Матрица экспертных правил](./business-logic/expert_rules_matrix.md) — Сводная таблица всех технологических инцидентов, триггеров срабатывания, ожидаемых эффектов и рекомендаций **(Основное ТЗ для Вики)**.
* [Математическая модель физики](./business-logic/physics_model.md) — Формулы из теории автоматического управления для эмуляции роста температур купола и дымовых газов.

### 3. Контракты и API
Строгие интерфейсы взаимодействия между Frontend и Backend приложениями.
* [Спецификация REST API (OpenAPI)](./contracts/openapi.yaml) — Описание синхронных эндпоинтов (история телеметрии, справочники, команды управления).
* [Спецификация WebSockets (STOMP)](./contracts/websockets_stomp.md) — Описание топиков (потоки телеметрии, алерты, статус системы) и форматов JSON-сообщений для real-time передачи данных. **(Основное ТЗ для Влада)**.

### 4. База данных
Схемы и структуры хранения временных рядов и доменных объектов в PostgreSQL.
* [ER-диаграмма](./database/schema_er.md) — Визуальная схема таблиц, связей, перечислений (ENUM) и типов данных.

### 5. Регламенты
Правила разработки. Обязательно к прочтению перед началом.
* [Регламент разработки](./guidelines/development_flow.md) — Правила работы с Git, оформление PR, пайплайны CI/CD и Code Review.
